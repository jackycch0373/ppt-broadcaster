Presenter Setup Guide

  1. Download: Get the .ppam file from the home page.
  2. Unblock File: Right-click the downloaded file > Properties. At the bottom, check Unblock and click OK. (Required by Windows Security).
  3. Open PowerPoint: Go to File > Options > Add-ins.
  4. Install: At the bottom, set Manage to PowerPoint Add-ins and click Go.
  5. Activate: Click Add New, select the .ppam file, and ensure it is checked in the list.
  6. Broadcast: Use the "Live Web" tab now appearing in your PowerPoint Ribbon.
